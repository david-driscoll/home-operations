# gluetun's /iptables/post-rules.txt (docs/plans/region-exits.md §D3).
#
# gluetun runs each line starting `iptables `, `iptables-nft ` or
# `iptables-legacy ` with the backend it detected, and skips every other line
# (internal/firewall/iptables.go runUserPostRules). On Talos that backend is
# nft. It applies them once, when its firewall is enabled at startup;
# reconnects and region switches only swap the VPN-server rules
# (internal/firewall/vpn.go), so these stay.
#
# Every line here must start `iptables -A`: gluetun execs each one as an
# argument list (no shell, so no `-C ... ||` guard), and undoes them on a
# failed enable by turning a LEADING -A into -D (flipRule). The nat
# MASQUERADE rules are therefore in routing.sh instead, guarded there: a
# `-t nat -A` line would never be flipped, and gluetun's disable flushes only
# `filter`, so a rollback or a gluetun restart would stack duplicates.
#
# The kill switch itself is NOT here: it is the mangle FORWARD drop in
# routing.sh. tailscaled's ts-forward accepts client traffic before
# gluetun's FORWARD policy is reached, so filter-table rules cannot fail
# closed on their own.
#
# Client traffic from tailscale0 out the tunnel, and the replies back.
iptables -A FORWARD -i tailscale0 -o tun0 -j ACCEPT
iptables -A FORWARD -i tun0 -o tailscale0 -m conntrack --ctstate ESTABLISHED,RELATED -j ACCEPT
# tailscaled's own packets (routing.sh rule 90) through gluetun's OUTPUT DROP
# policy, out eth0 to the home WAN.
iptables -A OUTPUT -o eth0 -m mark --mark 0x80000/0xff0000 -j ACCEPT
#
# NetBird (#3139): the same, for wt0 and its overlay. NetBird inserts its own
# `-i wt0 -j ACCEPT` ahead of these; they keep forwarding to the tunnel
# explicit if that changes.
iptables -A FORWARD -i wt0 -o tun0 -j ACCEPT
iptables -A FORWARD -i tun0 -o wt0 -m conntrack --ctstate ESTABLISHED,RELATED -j ACCEPT
# NetBird's own packets (routing.sh rule 91), out eth0 to the home WAN.
iptables -A OUTPUT -o eth0 -m mark --mark 0x1bd00 -j ACCEPT
# Nothing accepts forwarded traffic to eth0: the region exit fails closed.
